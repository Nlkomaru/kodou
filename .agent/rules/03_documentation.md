# ドキュメント

## ドキュメントの作成

- コードを記述した後に、`docs/content/` に mdx ファイルを作成、または既存の mdx ファイルに追記してドキュメントを作成してください。
- なお、文章の文体について、その他の部分で指示があったとしても、ドキュメントに関しては、あくまでも指示された文章の文体で記載してください。
- 見やすくするために icon を付けることが推奨されますが、最上位のみにしてください。Fumadocs の絵文字を利用してください。

## Storybook

- 新しい UI コンポーネントを作成した際は、`app/src/` に対応する `*.stories.tsx` ファイルを作成し、Storybook 上で確認できるようにしてください。
