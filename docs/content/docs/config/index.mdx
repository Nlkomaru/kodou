title: 設定
description: Kodou の設定項目と既定値の一覧
---

Kodou の設定は [設定ファイル `config.conf`](/docs/config/config-file) にまとまっています。
アプリの UI で切り替えられるのは **OSC 送信のオン・オフだけ**で、それ以外はすべて設定ファイルを編集して変更します。

`config.conf` は初回起動時に自動生成されます。編集後はアプリを再起動すると反映されます。

VRChat 側でも OSC を有効にする必要があります（ラジアルメニュー → Options → OSC → Enabled）。

## OSC 送信先

| 項目 | 既定値 | 説明 |
| --- | --- | --- |
| `osc.targets` | `["127.0.0.1:9000"]` | 送信先の `"ip:port"` 配列。複数書くと、すべての送信先へ同じ値を送ります。同一 PC で VRChat を動かす場合は既定のままで動作します |
| OSC 送信の有効化 | 無効 | UI のスイッチ。無効の間は、`config.conf` に書いた送信先へも送信しません |

## 送信するパラメータ

送信する Avatar Parameter は、`config.conf` の `compatibility` セクションで指定します。
パラメータごとに送信先アドレスを配列で書き、空配列にするとそのパラメータは送信しません。

既定のアドレスは VRCOSC 互換で、VRCOSC に対応するものが無いパラメータは Kodou 標準アドレス `/avatar/parameters/Kodou/...` を使います。
1つのパラメータに複数のアドレスを書けば、同じ値を複数のギミックへ同時に送れます。

書式と既定値の一覧は [設定ファイル](/docs/config/config-file#compatibility-セクション) を、各パラメータのアドレスと型は [送信される情報](/docs/osc) を参照してください。

## 心拍値の変換

| 項目 | 既定値 | 説明 |
| --- | --- | --- |
| `osc.bpmMin` / `osc.bpmMax` | `0` / `240` | `HRNormalised` と `HRFloat` を計算するときの正規化範囲。VRCOSC の既定値に合わせています |
| `osc.hrFloatMode` | `"signed"` | `HRFloat` の範囲。`"signed"` は `-1.0` 〜 `1.0`、`"unsigned"` は `0.0` 〜 `1.0` |
| `osc.averageWindowMs` | `10000` | `HRAverage` を計算する対象期間（ms）。直近10秒の平均 |

自分の安静時心拍に合わせて下限・上限を調整すると、`HRNormalised` の変化がアバター側で見やすくなります。

## 拍の検出

| 項目 | 既定値 | 説明 |
| --- | --- | --- |
| `osc.beatPulseMs` | `120` | `BeatPulse` を `true` にしてから `false` へ戻すまでの時間（ms）。次の拍に被らないよう、拍周期の1/4と120msの小さい方が使われます |
| `osc.rrTwitchThresholdMs` | `50` | 連続する [RR間隔](/docs/metrics/rr-interval) の差がこの値を超えたときに `RRTwitchUp` / `RRTwitchDown` を発火させます |

## 他ツール向けアバターへの対応

VRCOSC 向けに作られたアバターは、既定の設定のまま動作します。
その他のギミックに合わせたい場合は、`compatibility` セクションでアドレスを書き換えてください。

詳細は [互換性](/docs/config/compatible/osc) を参照してください。

## 再接続

デバイスとの接続が切れた場合、Kodou は自動で再接続を試みます。
再接続の間隔は指数バックオフ（1秒から始まり最大30秒）で、この挙動に設定項目はありません。
再接続中は `Reconnecting` が `true` になります。

## 記録

デバイスに接続すると、心拍データの記録が自動で始まります。設定項目はありません。
保存先とファイル名の規則は [記録](/docs/implementation#記録) を参照してください。
