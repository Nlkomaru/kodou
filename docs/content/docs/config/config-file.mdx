---
title: 設定ファイル
description: config.conf で OSC の送信先を複数指定する
---

アプリ内の UI で入力した OSC 送信先は、アプリを閉じると失われます。
常用する送信先を保存しておきたい場合や、送信先を複数指定したい場合は、設定ファイル `config.conf` に書きます。

書式は [HOCON](https://github.com/lightbend/config/blob/main/HOCON.md) です。
初回起動時にテンプレートが自動生成されるため、通常は生成されたファイルを編集するだけで済みます。

## 保存場所

`config.conf` はアプリのデータディレクトリ直下に置かれます。

| OS | パス |
| --- | --- |
| Windows | `%APPDATA%\dev.nikomaru.kodou\config.conf` |
| macOS | `~/Library/Application Support/dev.nikomaru.kodou/config.conf` |
| Linux | `~/.local/share/dev.nikomaru.kodou/config.conf` |

## 書式

初回起動時に生成されるテンプレートは次の内容です。

```text
// Kodou 設定ファイル (HOCON形式)
// 複数のOSC送信先を配列で指定できます。
// ここに書いた送信先は、GUIの送信先設定と統合して使われます。

osc {
  targets = [
    "127.0.0.1:9000"
  ]
}
```

### osc.targets

OSC の送信先を `"ip:port"` の配列で指定します。
複数書くと、同じパラメータをすべての送信先へ送ります。
VRChat が OSC を待ち受けるアドレスは通常 `127.0.0.1:9000` です。

```text
osc {
  targets = [
    // 同じPCで動く VRChat
    "127.0.0.1:9000",
    // 別PCのOSCアプリにも同時に送る
    "192.168.1.100:9001"
  ]
}
```

## UI の送信先との関係

実際の送信先は、`config.conf` の `osc.targets` と UI で入力した送信先を**統合したもの**です。
どちらか一方だけが使われるのではなく、両方へ送信します。
同じ `"ip:port"` が両方に書かれている場合は、二重送信しないよう1つにまとめられます。

```text
実際の送信先 = config.conf の targets ∪ UI の送信先
```

- 送信のオン・オフは UI の「送信を有効化」スイッチが優先されます。無効の間は、`config.conf` に書いた送信先へも送信しません。
- `config.conf` は起動時に一度だけ読み込まれます。編集したらアプリを再起動してください。
- ファイルが無い、または書式が壊れている場合、`config.conf` の送信先は無視され、UI で入力した送信先だけが使われます。

:::warn
`config.conf` に書いた送信先は UI のテキストエリアには表示されず、その下に「config.conf の送信先にも併せて送信します」と表示されます。
意図しない送信先が残っていないか、UI の表示で確認してください。
:::
