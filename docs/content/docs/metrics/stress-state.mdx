title: 自律神経状態の判定
description: HR と HRV から「落ち着いている / 普通 / ストレス・興奮」を推定する方法と、その限界
---

心拍データから「いま落ち着いているか、ストレスを感じているか」を推定し、アバターの表情やエフェクトに反映させたい、というのがこのページの主題です。

結論から言うと、**心拍データだけで区別できるのは「覚醒度（arousal）が高いか低いか」の1軸だけ**です。
ストレスと興奮はどちらも交感神経が優位になった状態で、心拍上の現れ方はほとんど同じです。
まずこの前提を押さえた上で、実用的な判定方法を組み立てます。

## 何が測れて、何が測れないか

心理状態はよく **覚醒度（高い⇔低い）** と **感情価（快⇔不快）** の2軸で整理されます [^5]。

|  | 快（ポジティブ） | 不快（ネガティブ） |
| --- | --- | --- |
| **覚醒度：高** | 興奮・熱中 | ストレス・緊張・不安 |
| **覚醒度：低** | 落ち着き・リラックス | 退屈・疲労 |

心拍と HRV が反映するのは、このうち**覚醒度の軸だけ**です。
楽しくて興奮しているときも、緊張して不安なときも、交感神経が優位になり心拍数は上がり HRV は下がります。
どちらなのかを分ける情報（感情価）は、心拍データには含まれていません。

:::warn
「ストレスを感じている」と「興奮している」を心拍だけで区別することはできません。
両者を分けたい場合は、VRChat 上の文脈（どのワールドにいるか、何をしているか）や、ユーザー自身の申告といった心拍以外の情報が必要です。
:::

したがって Kodou でできるのは、**覚醒度を3段階に分けること**です。

- 落ち着いている（副交感神経優位）
- 普通（平常時）
- 高覚醒（交感神経優位）＝ ストレスまたは興奮

## 使う指標

各指標が自律神経のどちらを反映するかをまとめます [^1][^2][^3]。

| 指標 | 交感神経 | 副交感神経 | 覚醒度判定での信頼性 | Kodou |
|------|---------|-----------|--------------------|-------|
| [HR](/docs/metrics/hr) | 上昇させる | 低下させる | ★★★★★ | 実装済み |
| [RMSSD](/docs/metrics/time-domain/rmssd) | ほぼ無関係 | 強く反映 | ★★★★★ | 実装済み |
| [pNN50](/docs/metrics/time-domain/pnn50) | ほぼ無関係 | 強く反映 | ★★★★★ | 未実装 |
| [HF](/docs/metrics/frequency-domain/hf) | ほぼ無関係 | 強く反映 | ★★★★☆ | 未実装 |
| [SDNN](/docs/metrics/time-domain/sdnn) | 両方を含む | 両方を含む | ★★★☆☆ | 未実装 |
| [LF](/docs/metrics/frequency-domain/lf) | 主に交感神経 | 一部影響 | ★★☆☆☆ | 未実装 |
| [LF/HF](/docs/metrics/frequency-domain/lf-over-hf) | 上昇 | 低下 | ★★☆☆☆ | 未実装 |

現時点で Kodou が算出できるのは **HR と RMSSD** です。
この2つは表の上位2つでもあるため、実用上はこの組み合わせで十分に機能します。

**HR が上がり、RMSSD が下がる**ほど覚醒度が高い、というのが判定の基本形です。

## 個人のベースラインを基準にする

HRV の絶対値は個人差が非常に大きく、年齢・体力・普段の姿勢で数倍変わります [^2]。
`RMSSD が 50ms 以上ならリラックス` のような固定しきい値は、一般論としては書けますが、**特定の個人に当てはめると外れます**。

そのため判定は、**その人自身の平常時（ベースライン）からの相対変化**で行います。

### ベースラインの取り方

1. 座って落ち着いた状態で5分ほど計測する
2. その間の平均 HR と平均 RMSSD を記録する（これがベースライン `HR₀` と `RMSSD₀`）
3. 以降はこの値との比で判定する

ベースラインは体調・時刻・カフェイン摂取などで日々変わるため、セッション開始時に取り直すのが理想です。

### 判定ロジック

ベースラインからのずれを、標準偏差ではなく単純な比率で見る形にすると実装が軽く済みます。

```
hrRatio    = currentHR / HR₀          // 1.0 より大きいほど心拍が速い
rmssdRatio = currentRMSSD / RMSSD₀    // 1.0 より小さいほど HRV が低い

arousal = (hrRatio - 1.0) + (1.0 - rmssdRatio)
```

`arousal` は 0 付近が平常、正の方向に大きいほど高覚醒です。

| `arousal` | 状態 | 解釈 |
| --- | --- | --- |
| −0.15 未満 | 落ち着いている | 副交感神経優位。HR が平常より低く、HRV が高い |
| −0.15 〜 0.20 | 普通 | 平常時の範囲 |
| 0.20 以上 | 高覚醒 | 交感神経優位。ストレスまたは興奮 |

:::info
この境界値（−0.15 / 0.20）は Kodou 向けの**経験的な目安**であり、論文由来の基準値ではありません。
アバター側の演出が過敏に切り替わる／まったく切り替わらない場合は、自分に合わせて調整してください。
:::

### チャタリング対策

判定を毎秒切り替えるとアバターの表情が細かく揺れて不自然になります。実装時は次のどちらかを入れてください。

- **ヒステリシス**: 状態を上げるしきい値と下げるしきい値をずらす（例：0.20 で高覚醒に入り、0.15 を下回るまで戻さない）
- **保持時間**: 一度状態が変わったら最低10秒は維持する

## 判定を歪める要因

心拍データは心理状態以外にも強く反応します。以下を考慮しないと、単なる身体活動をストレスと誤判定します。

| 要因 | 影響 |
| --- | --- |
| **身体運動** | フルトラで踊れば当然 HR は上がり RMSSD は下がる。ストレスではない |
| **姿勢** | 立位は臥位より HR が高く HRV が低い |
| **呼吸** | 深くゆっくり呼吸すると RMSSD は大きく上がる。意図的に操作できてしまう |
| **カフェイン・アルコール** | 数時間単位でベースラインをずらす |
| **計測ノイズ** | 胸ベルトのずれや光学式センサーの体動ノイズで RR間隔が乱れ、RMSSD が跳ね上がる |

姿勢・呼吸・時間帯といった条件を揃えることの重要性は、HRV 研究の実施ガイドラインでも繰り返し指摘されています [^4]。

特に**計測ノイズ**は実害が大きく、異常な RR間隔（前後の値から大きく外れるもの）は RMSSD 計算から除外するのが定石です。
VRChat では**身体運動**の影響も避けられないため、判定結果は「ストレス度」ではなく「覚醒度」として扱うほうが誠実です。

## アバター制御への応用

判定結果をどう使うかの例です。Kodou は状態そのものを OSC で送ってはいないため、現時点ではアバター側の Animator で `Kodou/HR` などから組む形になります。

| やりたいこと | 使う値 | 実装の方向性 |
| --- | --- | --- |
| 動悸エフェクト | `Kodou/BeatPulse` | 拍ごとの bool を心臓アイコンの拡大に繋ぐ |
| 心拍の速さを連続的に見せる | `Kodou/HRNormalised` | 0.0〜1.0 を Blend Tree に流す。BPM 下限・上限は自分の値に設定する |
| リラックス表現 | RMSSD の上昇 | 現状は OSC 未送信。アプリ側の統計表示で確認する |
| 呼吸アニメーション同期 | HF 帯域 | 周波数領域解析が必要で未実装 |

各パラメータのアドレスと型は [送信される情報](/docs/osc)、正規化範囲などの設定は [設定](/docs/config) を参照してください。

:::warn
Kodou は医療機器ではありません。
ここで説明する判定は VRChat での演出を目的とした推定であり、健康状態やストレスの診断に使えるものではありません。
:::
