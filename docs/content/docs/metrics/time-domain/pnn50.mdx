## 説明

**pNN50** は、隣接する RR間隔の差が 50 ms を超える割合（%）です。RMSSD と同様に**副交感神経活動**を反映し、両者は高い相関を示します [^1]。

- **反映するもの**: 副交感神経活動
- **特徴**: 計算が単純で直感的に理解しやすい。閾値 50ms は若年成人向けであり、年齢や個人差を考慮する必要がある。

## 計算方法

```
pNN50 = (隣接 RR 差が 50ms を超えた回数 / (N - 1)) × 100 (%)
```

1. すべての隣接 RR間隔の差を計算
2. 差の絶対値が 50ms を超えるペアをカウント
3. 全ペア数（N-1）で割り、100 を掛ける

## 正常値

| 年齢層 | 正常範囲（5分安静時） |
|--------|---------------------|
| 成人（若年） | 20 〜 40 % |
| 成人（中高年） | 10 〜 30 % |
