## 説明

**RMSSD** は、隣接する RR間隔の差の二乗平均平方根です。短期的な変動成分を抽出するため、**副交感神経活動**を純度良く反映する指標として広く用いられています [^1][^2]。

- **反映するもの**: 副交感神経活動（特に呼吸性洞性不整脈 RSA）
- **特徴**: 測定時間の長さの影響を受けにくく、短時間計測でも信頼性が高い。pNN50 と高い相関を示す。

## 計算方法

```
RMSSD = sqrt( Σ(RRᵢ₊₁ - RRᵢ)² / (N - 1) )
```

- RRᵢ₊₁ - RRᵢ：隣接する RR間隔の差
- 各差を二乗して合計し、N-1 で割り、平方根を取る

## 正常値

| 年齢層 | 正常範囲（5分安静時） |
|--------|---------------------|
| 成人（一般） | 20 〜 50 ms |
| 成人（アスリート） | 50 〜 100 ms |
