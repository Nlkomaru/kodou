## 説明

**SDNN** は、すべての正常な RR間隔（NN間隔：Normal-to-Normal intervals）の標準偏差です。HRV の全体的な大きさを表す最も基本的な指標です [^1]。

- **反映するもの**: 自律神経全体の活動（交感神経＋副交感神経）。呼吸・血圧変動・体温調節などの周期成分すべてを含む。
- **特徴**: 測定時間に依存して値が大きくなるため、異なる測定時間の SDNN を比較しないよう注意が必要（5分測定と24時間測定では基準値が大きく異なる）。

## 計算方法

N 個の正常な RR間隔 RR₁, RR₂, ..., RRₙ について：

```
SDNN = sqrt( Σ(RRᵢ - RR̄)² / (N - 1) )
```

ここで RR̄ は全 RR間隔の平均値です。

## 正常値

| 測定時間 | 正常範囲 |
|----------|---------|
| 5分間（安静時） | 30 〜 100 ms |
| 24時間（Holter） | 100 〜 200 ms |
