## 説明

**LF/HF 比**は、[LF](/docs/metrics/frequency-domain/lf) と [HF](/docs/metrics/frequency-domain/hf) のパワー比です。
**交感神経と副交感神経のバランス**（sympathovagal balance）を表すとして広く使われてきました [^1]。

- **高い LF/HF**: 交感神経優位（ストレス・緊張状態）とされる
- **低い LF/HF**: 副交感神経優位（リラックス状態）とされる

:::warn
LF/HF 比の解釈には学術的な議論があります。
LF は純粋な交感神経の指標ではなく副交感神経の影響も受けるため、この比を「自律神経バランス」として読むことの妥当性は否定的に評価されています [^2]。
個人差や測定条件（呼吸数・姿勢）の影響も大きいため、LF/HF 単独での判断は避け、複数の指標と合わせて評価してください [^3]。
:::

## 計算方法

```
LF/HF = LF (ms²) / HF (ms²)
```

正規化単位（n.u.）を用いる場合：

```
LF n.u. = LF / (Total Power - VLF) × 100
HF n.u. = HF / (Total Power - VLF) × 100
LF/HF = LF n.u. / HF n.u.
```

## 正常値

| 状態 | LF/HF |
|------|-------|
| 安静時（成人） | 0.5 〜 2.0 |
| ストレス時 | 2.0 〜 5.0+ |
| 深いリラックス時 | 0.5 未満 |

いずれも目安です。同じ人でも計測条件によって大きく変わります。
