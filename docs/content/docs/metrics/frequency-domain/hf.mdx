## 説明

**HF** は 0.15〜0.40 Hz の高周波成分のパワーです。呼吸に伴う心拍変動（RSA: Respiratory Sinus Arrhythmia）を反映します [^1]。

- **反映するもの**: **副交感神経活動**。HF が高いほど副交感神経が優位に働いていることを示す。
- **単位**: ms²（絶対値）
- **注意**: 呼吸数がこの帯域から外れる場合（遅すぎる／速すぎる）、帯域の調整が必要です。

## 計算方法

```
HF = ∫₀.₁₅^0.40 PSD(f) df
```

## 正常値

5分間の安静時計測における目安 [^2]：

| 状態 | HF (ms²) |
|------|---------|
| 安静時（成人） | 200 〜 1000 |
| 副交感神経優位時 | 上昇 |
| ストレス時 | 低下 |

HF も LF と同様に個人差が大きいため、絶対値ではなく自分の平常時からの増減で見るのが実用的です。
