---
title: はじめに
description: Kodou の目的と概要
---

Kodou は、Bluetooth の心拍センサー（HRM）から心拍データを取得し、OSC 経由で VRChat のアバターへ送るデスクトップアプリケーションです。

心拍数をアバターに表示するだけでなく、心拍変動（HRV）から自分の状態を推定してアバターの演出に使うことを目指しています。

## できること

- [x] Bluetooth HRM デバイスの検出と接続（BLE Heart Rate Service）
- [x] 心拍数・RR間隔・バッテリー残量の取得
- [x] 接続断からの自動再接続（指数バックオフ）
- [x] VRChat への OSC 送信（`/avatar/parameters/Kodou/...`）
- [x] VRCOSC / iron-heart 互換モード
- [x] 送信パラメータの個別 ON/OFF
- [x] 統計表示（平均・最大・最小 BPM、RMSSD）
- [ ] 周波数領域の HRV 解析（LF / HF）
- [ ] 自律神経状態の判定結果を OSC 送信

:::warn
Kodou は医療機器ではありません。取得・表示される値は VRChat での演出を目的としたものであり、健康状態の診断には使えません。
:::
