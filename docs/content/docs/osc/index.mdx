このページでは、VRChat に送る予定の OSC パラメータを整理します。

参考実装として、VRCOSC の [`HeartrateModule.cs`](https://github.com/VolcanicArts/VRCOSC/blob/7e5fa96c981a23e2a8b78ac4501bf2fa4deb223c/VRCOSC.App/SDK/Modules/Heartrate/HeartrateModule.cs) を確認しています。
VRCOSC では `VRCOSC/Heartrate/...` というパラメータ名で登録されており、VRChat の Avatar Parameter OSC では通常 `/avatar/parameters/VRCOSC/Heartrate/...` へ送信する形になります。

また、iron-heart の [`settings.rs`](https://github.com/nullstalgia/iron-heart/blob/784c3645353b32250df1691efa052277361d6879/src/settings.rs#L186) と README の既定設定も参考にしています。
iron-heart では `prefix = "/avatar/parameters/"` の下に、`isHRConnected` や `HR` などの短い Avatar Parameter 名を置く構成です。

## 実装状況

- [x] VRChat への OSC 送信
- [x] VRCOSC 互換の心拍パラメータ送信
- [x] iron-heart 互換の心拍パラメータ送信
- [x] 送信するパラメータを選ぶチェックボックス UI

現時点のアプリは、Bluetooth Heart Rate Monitor から心拍データを取得し、Tauri イベントとして React 側に渡します。
OSC 送信は Rust 側（rosc）で UDP 送信し、React 側のチェックボックスで各パラメータの有効・無効と互換モードを切り替えられます。

この表の各行はアプリ内のチェックボックスで個別に有効・無効化できます。

| 実装 | iron-heart 名 | OSC アドレス | 型 | Kodou 標準での対応 |

| [x] | `isHRConnected` | `/avatar/parameters/isHRConnected` | `bool` | `Kodou/Connected` |
| [x] | `isHRReconnecting` | `/avatar/parameters/isHRReconnecting` | `bool` | `Kodou/Reconnecting` |
| [x] | `HRBattery` | `/avatar/parameters/HRBattery` | `int` | `Kodou/Battery` |
| [x] | `HRBatteryFloat` | `/avatar/parameters/HRBatteryFloat` | `float` | `Kodou/BatteryFloat` |
| [x] | `HeartBeatToggle` | `/avatar/parameters/HeartBeatToggle` | `bool` | `Kodou/BeatToggle` |
| [x] | `isHRBeat` | `/avatar/parameters/isHRBeat` | `bool` | `Kodou/BeatPulse` |
| [x] | `HR` | `/avatar/parameters/HR` | `int` | `Kodou/HR` |
| [x] | `floatHR` | `/avatar/parameters/floatHR` | `float` | `Kodou/HRFloat` |
| [x] | `RRInterval` | `/avatar/parameters/RRInterval` | `int` | `Kodou/RRInterval` |
| [x] | `HRTwitchUp` | `/avatar/parameters/HRTwitchUp` | `bool` | `Kodou/RRTwitchUp` |
| [x] | `HRTwitchDown` | `/avatar/parameters/HRTwitchDown` | `bool` | `Kodou/RRTwitchDown` |

iron-heart の `RRInterval` は `int` ですが、README では「値が大きくなりやすく同期用途には向かず、主にローカルデバッグ用」と説明されています。
VRChat の Avatar Parameter として実用する場合は、`RRTwitchUp` / `RRTwitchDown` のような bool トリガーのほうが扱いやすいです。

## アプリ内データとの対応

| Kodou アドレス | 現在取得できるデータ | 備考 |
| --- | --- | --- |
| `Kodou/Connected` | `heart-rate-status.state === "connected"` | 取得済み |
| `Kodou/HR` | `heart-rate-reading.bpm` | 取得済み |
| `Kodou/RRInterval` | `heart-rate-reading.rrIntervalsMs` の最新値 | 取得済み |
| `Kodou/Battery` | `heart-rate-reading.batteryPercent` | デバイスが Battery Service を公開している場合のみ取得 |
| `Kodou/BeatToggle` / `Kodou/BeatPulse` | `bpm` から拍間隔を推定して生成 | 実装済み（拍周期タイマーで送信） |
| `Kodou/HRAverage` | BPM 履歴から計算 | 実装済み（平均窓は UI で設定可能、既定 10000ms） |
| `Kodou/HRNormalised` / `Kodou/HRFloat` | `bpm` から計算 | 実装済み（下限・上限と HRFloat の範囲は UI で設定可能） |
| `Kodou/RRTwitchUp` / `Kodou/RRTwitchDown` | 連続する RR interval の差分から計算 | 実装済み（しきい値は UI で設定可能、既定 50ms） |
| `Kodou/Reconnecting` | 自動再接続中 `true` | 実装済み（Rust 側で指数バックオフ再接続） |
| `Kodou/Activity` | 未実装 | アクティビティ選択 UI を追加する場合に使用 |

## 送信値の計算

### Value

`Value` は現在の心拍数 BPM です。
VRCOSC では `SmoothValue` が有効な場合、受信した BPM に即座にジャンプせず、設定された時間で目標値へ近づくように補間されます。

このアプリで実装する場合、まずは補間なしで `bpm` をそのまま `int` として送る想定です。

### Normalised

`Normalised` は、現在 BPM を任意の下限・上限 BPM にマッピングした `float` です。
VRCOSC の既定値では下限が `0`、上限が `240` です。

```text
normalised = (currentBpm - lowerBound) / (upperBound - lowerBound)
```

VRChat 側で扱いやすいよう、実装時は `0.0` から `1.0` に clamp します。

### Average

`Average` は、指定期間内の BPM 平均です。
VRCOSC の既定値では `10000ms`、つまり直近10秒の平均です。

### Beat

`Beat` は、BPM から推定した拍間隔ごとに送られる `bool` です。

```text
delayMs = round(60 * 1000 / bpm)
```

Beat Mode が無効な場合は、拍ごとに `true` / `false` が交互に切り替わります。
Beat Mode が有効な場合は、拍ごとに `true` を送り、短時間後に `false` へ戻します。

### Legacy digits

旧形式の `Units` / `Tens` / `Hundreds` は、BPM を3桁に分解して各桁を `10` で割った `float` として送ります。

例: `123 BPM`

| パラメータ | 値 |
| --- | --- |
| `Hundreds` | `0.1` |
| `Tens` | `0.2` |
| `Units` | `0.3` |
