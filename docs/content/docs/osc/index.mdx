このページでは、Kodou が送信できる OSC パラメータを整理します。

**どのパラメータをどのアドレスへ送るかは、[設定ファイル](/docs/config/config-file) の `compatibility` セクションが決めます。**
既定のアドレスは VRCOSC 互換で、VRCOSC に対応するものが無いパラメータは Kodou 標準アドレス `/avatar/parameters/Kodou/...` を使います。

参考実装として、VRCOSC の [`HeartrateModule.cs`](https://github.com/VolcanicArts/VRCOSC/blob/7e5fa96c981a23e2a8b78ac4501bf2fa4deb223c/VRCOSC.App/SDK/Modules/Heartrate/HeartrateModule.cs) を確認しています。
VRCOSC では `VRCOSC/Heartrate/...` というパラメータ名で登録されており、VRChat の Avatar Parameter OSC では通常 `/avatar/parameters/VRCOSC/Heartrate/...` へ送信する形になります。

## 実装状況

- [x] VRChat への OSC 送信
- [x] VRCOSC 互換の心拍パラメータ送信
- [x] 送信するパラメータとアドレスを設定ファイルで指定
- [x] 1つのパラメータを複数アドレスへ複製送信
- [x] 複数の送信先への同時送信

現時点のアプリは、Bluetooth Heart Rate Monitor から心拍データを取得し、Tauri イベントとして React 側に渡します。
OSC 送信は Rust 側（rosc）で UDP 送信します。UI では送信のオン・オフだけを切り替え、送信内容は `config.conf` で決めます。

## 送信先

送信先は `config.conf` の `osc.targets` に `"ip:port"` 形式で指定します。
複数書くと、指定したすべての送信先へ同じパラメータを送ります。
VRChat の Avatar Parameter OSC は通常 `127.0.0.1:9000` で待ち受けます。

## パラメータ一覧

下表の「Kodou アドレス」は、`compatibility` セクションで別のアドレスを指定しなかった場合に使われる Kodou 標準アドレスです。
既定で VRCOSC のアドレスへ送るパラメータは、[設定ファイル](/docs/config/config-file#既定のアドレス) の表を参照してください。

「設定キー」が `compatibility` セクションに書くキー名です。

| 設定キー | Kodou 標準アドレス | 型 | 対応する値 | 既定 |
| --- | --- | --- | --- | --- |
| `connected` | `/avatar/parameters/Kodou/Connected` | `bool` | 心拍データを受信中なら `true` | VRCOSC へ送信 |
| `reconnecting` | `/avatar/parameters/Kodou/Reconnecting` | `bool` | 一時切断を隠して再接続扱いにしている間 `true` | Kodou へ送信 |
| `hr` | `/avatar/parameters/Kodou/HR` | `int` | 現在の心拍数 BPM | VRCOSC へ送信 |
| `hrFloat` | `/avatar/parameters/Kodou/HRFloat` | `float` | 心拍数を float 化した値。既定は `-1.0` から `1.0`、設定次第で `0.0` から `1.0` | Kodou へ送信 |
| `hrNormalised` | `/avatar/parameters/Kodou/HRNormalised` | `float` | 下限・上限 BPM から `0.0` から `1.0` に正規化した心拍数 | VRCOSC へ送信 |
| `hrAverage` | `/avatar/parameters/Kodou/HRAverage` | `int` | 指定期間内の平均 BPM | VRCOSC へ送信 |
| `battery` | `/avatar/parameters/Kodou/Battery` | `int` | 心拍センサーのバッテリー残量 `0` から `100` | Kodou へ送信 |
| `batteryFloat` | `/avatar/parameters/Kodou/BatteryFloat` | `float` | バッテリー残量 `0.0` から `1.0` | Kodou へ送信 |
| `beatToggle` | `/avatar/parameters/Kodou/BeatToggle` | `bool` | 拍ごとに `true` / `false` を交互に切り替える | VRCOSC へ送信 |
| `beatPulse` | `/avatar/parameters/Kodou/BeatPulse` | `bool` | 拍ごとに短時間だけ `true` | 送信しない |
| `rrInterval` | `/avatar/parameters/Kodou/RRInterval` | `int` | 最新 RR interval。単位は ms | Kodou へ送信 |
| `rrTwitchUp` | `/avatar/parameters/Kodou/RRTwitchUp` | `bool` | RR interval がしきい値以上に増えたとき、短時間だけ `true` | 送信しない |
| `rrTwitchDown` | `/avatar/parameters/Kodou/RRTwitchDown` | `bool` | RR interval がしきい値以上に減ったとき、短時間だけ `true` | 送信しない |
| `activity` | `/avatar/parameters/Kodou/Activity` | `int` | 選択中のアクティビティ番号 `0` から `255`（未実装） | 送信しない |

`beatToggle` と `beatPulse` は VRCOSC ではどちらも `Beat` に対応するため、既定では `beatToggle` のみを送信します。

`RRInterval` は値が大きく変化しやすいため、同期用途には向きません。
アバター側で拍の揺らぎを表現したい場合は、`RRTwitchUp` / `RRTwitchDown` のような bool トリガーのほうが扱いやすいです。

## アプリ内データとの対応

| Kodou アドレス | 現在取得できるデータ | 備考 |
| --- | --- | --- |
| `Kodou/Connected` | `heart-rate-status.state === "connected"` | 取得済み |
| `Kodou/HR` | `heart-rate-reading.bpm` | 取得済み |
| `Kodou/RRInterval` | `heart-rate-reading.rrIntervalsMs` の最新値 | 取得済み |
| `Kodou/Battery` | `heart-rate-reading.batteryPercent` | デバイスが Battery Service を公開している場合のみ取得 |
| `Kodou/BeatToggle` / `Kodou/BeatPulse` | `bpm` から拍間隔を推定して生成 | 実装済み（拍周期タイマーで送信） |
| `Kodou/HRAverage` | BPM 履歴から計算 | 実装済み（平均窓は `osc.averageWindowMs`、既定 10000ms） |
| `Kodou/HRNormalised` / `Kodou/HRFloat` | `bpm` から計算 | 実装済み（下限・上限は `osc.bpmMin` / `osc.bpmMax`、HRFloat の範囲は `osc.hrFloatMode`） |
| `Kodou/RRTwitchUp` / `Kodou/RRTwitchDown` | 連続する RR interval の差分から計算 | 実装済み（しきい値は `osc.rrTwitchThresholdMs`、既定 50ms） |
| `Kodou/Reconnecting` | 自動再接続中 `true` | 実装済み（Rust 側で指数バックオフ再接続） |
| `Kodou/Activity` | 未実装 | アクティビティ選択 UI を追加する場合に使用 |

## VRCOSC 互換パラメータ

| 実装 | パラメータ名 | OSC アドレス | 型 | 送信される値 |
| --- | --- | --- | --- | --- |
| [x] | `Connected` | `/avatar/parameters/VRCOSC/Heartrate/Connected` | `bool` | 心拍データを受信中なら `true`、未受信なら `false` |
| [x] | `Value` | `/avatar/parameters/VRCOSC/Heartrate/Value` | `int` | 現在の心拍数 BPM。スムージング設定が有効な場合は補間後の値を四捨五入 |
| [x] | `Normalised` | `/avatar/parameters/VRCOSC/Heartrate/Normalised` | `float` | 心拍数を下限・上限 BPM の範囲から `0.0` から `1.0` に正規化した値 |
| [x] | `Average` | `/avatar/parameters/VRCOSC/Heartrate/Average` | `int` | 指定期間内の平均心拍数 BPM。スムージング設定が有効な場合は補間後の値を四捨五入 |
| [x] | `Beat` | `/avatar/parameters/VRCOSC/Heartrate/Beat` | `bool` | 心拍タイミングで変化する値。Beat Mode が無効なら拍ごとに `true` / `false` をトグル、有効なら拍ごとに `true` になり短時間後に `false` へ戻る |
| [ ] | `Enabled` / `Units` / `Tens` / `Hundreds` | `/avatar/parameters/VRCOSC/Heartrate/...` | `bool` / `float` | BPM を3桁に分解して送る旧形式のパラメータ。Kodou では対応しません |

未受信時は `Connected` が `false` になり、`Value` / `Average` / `Normalised` は `0` 相当になります。

## 送信値の計算

### Value

`Value` は現在の心拍数 BPM です。
VRCOSC では `SmoothValue` が有効な場合、受信した BPM に即座にジャンプせず、設定された時間で目標値へ近づくように補間されます。

このアプリで実装する場合、まずは補間なしで `bpm` をそのまま `int` として送る想定です。

### Normalised

`Normalised` は、現在 BPM を任意の下限・上限 BPM にマッピングした `float` です。
VRCOSC の既定値では下限が `0`、上限が `240` です。

```text
normalised = (currentBpm - lowerBound) / (upperBound - lowerBound)
```

VRChat 側で扱いやすいよう、実装時は `0.0` から `1.0` に clamp します。

### Average

`Average` は、指定期間内の BPM 平均です。
VRCOSC の既定値では `10000ms`、つまり直近10秒の平均です。

### Beat

`Beat` は、BPM から推定した拍間隔ごとに送られる `bool` です。

```text
delayMs = round(60 * 1000 / bpm)
```

Beat Mode が無効な場合は、拍ごとに `true` / `false` が交互に切り替わります。
Beat Mode が有効な場合は、拍ごとに `true` を送り、短時間後に `false` へ戻します。
