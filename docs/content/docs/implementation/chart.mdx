---
title: チャートの時間軸
description: HR / RR-interval チャートの描画範囲と、データが途切れたときのふるまい
---

ダッシュボードの HR チャートと RR-interval チャートは、直近 60 秒を表示する時系列グラフです。

## 壁時計ベースの時間軸

チャートの X 軸は、受信したデータの範囲ではなく **現在時刻** を基準に決まります。
右端が常に「いま」で、左端がその 60 秒前です。この範囲は 1 秒ごとに更新されます。

データの範囲から軸を決めると、心拍センサーからの受信が途切れた瞬間に軸も止まってしまい、
グラフが「フリーズしている」のか「データが来ていない」のか区別できません。
時間軸を壁時計に固定することで、受信が止まっているあいだも軸が流れ続けます。

2 つのチャートは同じ時刻を共有するため、X 軸は常に揃います。

## データが途切れたとき

受信が途切れた区間は空白のまま表示します。グレーの帯や「データ待機中」のメッセージは表示しません。

- 折れ線と塗りつぶしは最後に受信した時点で終わります
- 受信が止まっても時間軸は進み、既存の波形はそのまま左へ流れます
- 60 秒以上データが来ない場合、すべての点が表示範囲から外れ、プロットは空白になります
- 初回の受信前もプロットは空白のままで、時刻目盛りだけが流れます
- 再接続してデータが再開すると、そのまま続きから描画されます

心拍センサーの接続が完全に切れた場合の自動停止については、
[設定ファイル](/docs/config/config-file) の `disconnectTimeoutSecs` を参照してください。

## 描画範囲と端の整列

HR と RR-interval は同じ描画幅・左右の余白を使い、見出しと統計値もプロットの端に揃えます。
スクロールバーの表示・非表示で横幅が変わらないよう、画面のスクロール領域には `scrollbar-gutter: stable` を指定しています。

時間窓の外側にある隣接点を平滑化・補間に使い、線と塗りつぶしの表示範囲は SVG の `clipPath` で固定します。
窓内の点だけを先に切り出す場合と異なり、時間窓が進んでも境界近くの値と傾きを保てます。
左右の時刻ラベルも SVG 内に収め、描画が画面の横方向へはみ出さないようにしています。

RR-interval は平滑化せず、受信した値のまま折れ線を描画します。統計値も引き続き受信値から計算します。

RR の通知には複数の間隔が含まれ、前回の通知より過去の時刻へさかのぼる場合があります。
履歴は受信順ではなく **時刻の昇順** に統合し、折れ線が過去へ折り返してから進むことを防ぎます。
受信値や推定時刻は変更せず、直近 60 秒・最大 96 点の保持制限も時刻順で適用します。


## 統計値への影響

チャート下部の統計値（最大・最小・平均・RMSSD・HRV）は、受信済みのデータだけから計算されます。
データが無い区間は計算に含まれないため、途切れによって平均値が引き下げられることはありません。

## 回帰テスト

TypeScript の型削除に対応した Node.js を使用し、リポジトリのルートで次を実行します。

```bash
node --experimental-strip-types --test app/src/lib/heart-rate.test.ts
```

複数の RR 値を含む通知の時刻が重なるケース、保持件数の上限で古いデータが後着するケース、
60 秒の保持期間の境界を確認します。
