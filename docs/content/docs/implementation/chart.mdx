---
title: チャートの時間軸
description: HR / RR-interval チャートの描画範囲と、データが途切れたときのふるまい
---

ダッシュボードの HR チャートと RR-interval チャートは、直近 60 秒を表示する時系列グラフです。

## 壁時計ベースの時間軸

チャートの X 軸は、受信したデータの範囲ではなく **現在時刻** を基準に決まります。
右端が常に「いま」で、左端がその 60 秒前です。この範囲は 1 秒ごとに更新されます。

データの範囲から軸を決めると、心拍センサーからの受信が途切れた瞬間に軸も止まってしまい、
グラフが「フリーズしている」のか「データが来ていない」のか区別できません。
時間軸を壁時計に固定することで、受信が止まっているあいだも軸が流れ続けます。

2 つのチャートは同じ時刻を共有するため、X 軸は常に揃います。

## データが途切れたとき

最後にデータを受信してから 3 秒以上経過すると、その区間が **「データ待機中」の帯** として表示されます。
帯には途切れてからの経過秒数も表示されます。

- 折れ線は最後に受信した時点で終わり、帯の区間には描画されません
- 帯は時間の経過とともに右へ広がっていきます
- 60 秒以上データが来ない場合、すべての点が表示範囲から外れ、チャート全体が「データ待機中」表示になります
- 再接続してデータが再開すると、そのまま続きから描画されます

心拍センサーの接続が完全に切れた場合の自動停止については、
[設定ファイル](/docs/config/config-file) の `disconnectTimeoutSecs` を参照してください。

## 統計値への影響

チャート下部の統計値（最大・最小・平均・RMSSD・HRV）は、受信済みのデータだけから計算されます。
データが無い区間は計算に含まれないため、途切れによって平均値が引き下げられることはありません。
